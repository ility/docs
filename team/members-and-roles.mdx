Everyone in a workspace has a role. The role decides what they can change.

## Roles

| | Owner | Member | Viewer |
| --- | :---: | :---: | :---: |
| See surfaces, scans, and issues | ✓ | ✓ | ✓ |
| Run, pause, and cancel scans | ✓ | ✓ | |
| Add surfaces and change surface settings | ✓ | ✓ | |
| Change issue status, assign, and comment | ✓ | ✓ | |
| Delete a surface | ✓ | | |
| Manage billing | ✓ | | |
| Create and revoke API keys | ✓ | | |
| Connect integrations | ✓ | | |
| Invite clients and limit what members can see | ✓ | | |

The person who creates a workspace is its first owner.

## Invite a teammate

<Steps>
  <Step title="Open the workspace switcher">
    Choose your workspace name at the top left of the app, then **Manage**.
  </Step>
  <Step title="Go to Members">
    Open the **Members** tab and choose **Invite**.
  </Step>
  <Step title="Send the invitation">
    Enter one or more email addresses and pick a role: **Admin** makes them an ility owner, and **Member** makes them a member. Choose **Send invitations**.
  </Step>
</Steps>

Your teammate gets an email with a link to join. Once they accept, they appear in the workspace with the role you chose.

You can change a teammate's role or remove them from the same **Members** tab. When someone leaves a workspace, any API keys they created there stop working straight away.

<Note>
  Want to give a client access to only their own sites? Use a [client invitation](/team/client-access) instead. It admits them already limited to the surfaces you choose.
</Note>

## Belong to more than one workspace

You can be a member of several workspaces, for example your own company's and a client's. Switch between them with the workspace switcher at the top left. Each workspace keeps its own surfaces, members, and billing.
