ility runs a [Model Context Protocol](https://modelcontextprotocol.io) (MCP) server, so AI assistants such as Claude, Claude Code, and Cursor can work with your workspace directly. Ask questions like "Which of our sites has the most critical issues?" or "Give me a fix for issue #42 on the marketing site", and the assistant looks up the answer in ility.

## Server URL

```text
https://app.ilitylabs.com/mcp
```

The server uses the streamable HTTP transport.

## Two ways to connect

  <Card title="Use an API key" icon="key" href="/mcp/connect#use-an-api-key">

## What the assistant can do

The assistant can list your workspaces, surfaces, scans, and issues, read an issue in full, get a ready-made fix prompt, and start a scan. See the [full list of tools](/mcp/tools).

Through MCP, the assistant never has more access than a member, even if you're an owner. It can't delete anything, change billing, or manage keys and members.

Starting a scan needs a plan that includes API triggers: Pro, an active trial, or Enterprise. Reading is available on every plan.
